Is your site actually up?

Paste a URL. StatusDog checks it from the outside — status code, response time, redirect chain and SSL certificate — and tells you what a visitor would see right now.

No sign-up. Nothing is stored on our side.

What you get

Honest up/down

A single blip is not an outage. StatusDog only calls a target down after a configurable number of consecutive failures, so you are not paged for one dropped packet.

The whole request

Every redirect hop, the final destination, response headers, and how many days are left on the TLS certificate.

A page for when it is down

Ship a real maintenance screen instead of a connection error — standalone, as middleware, or hosted here. See an example →

Watch it continuously

Add a URL to your dashboard and this browser re-checks it on an interval, tracking uptime and response time.

Where the history lives. Monitors are stored in this browser, and checks only run while a tab is open. For 24/7 monitoring that keeps running without you, use the CLI on a server you control — see the docs.

Or run it yourself

StatusDog is an MIT-licensed Node package with zero runtime dependencies. The same engine that powers this page runs on your own machine. 

npm install && npm run build
node dist/cli.js check https://example.com --expect 200
node dist/cli.js init && node dist/cli.js start

start runs the check loop and opens a local dashboard at 127.0.0.1:4321.
